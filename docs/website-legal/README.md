# Einbau in die öffentliche GitHub-Pages-Website

1. `datenschutz.html`, `impressum.html` und die beiden öffentlichen PDFs in das Website-Repository kopieren.
2. In jede öffentliche Seite im Footer Links zu `datenschutz.html` und `impressum.html` setzen.
3. Nach Gründung Telefonnummer, Register-/Steuerangaben und die Verbraucherschlichtungsangabe aktualisieren.
4. Die ladungsfähige Geschäftsanschrift nicht entfernen.
5. Falls später Tracking, Meta Pixel, eingebettete Social-Media-Inhalte oder Analysewerkzeuge hinzukommen, die Erklärung und Einwilligungssteuerung vorher anpassen.
